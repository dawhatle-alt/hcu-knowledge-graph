# EM-AAPI

Application Integrator / Automation API plugin deployments. One folder per deployed AI job type, one subfolder per version (`v0`, `v1`, ...), each holding the plugin XML, zip, protobuf definitions, and descriptor dictionary JSON. Useful for verifying which AI job type versions are deployed when diagnosing AI job issues.

**Parent:** [[EM]]
