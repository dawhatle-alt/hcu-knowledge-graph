# EM-DBT

Dumps of EM database tables as CSV/TXT: `PARAMS` (system parameters — input to [[Check-system_parameters]]), `confreg`/`commreg` registries, GCS tables, active users, LDAP groups, Reporting Facility user reports, add-ons, AI repository, and more. When a check references `DB: PARAMS`, this is where the raw data lives.

**Parent:** [[EM]]
