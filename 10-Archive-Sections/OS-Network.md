# OS-Network

Network state: hostname/DNS resolution (`Nslookup*`), interface and routing config, `Netstat`/`ss` socket state (including deep and timer variants), ping self-test, and `etc/` network config files. First stop for connectivity-class symptoms.

**Parent:** [[OS]]

## File inventory (normalized)

- `Hostname.txt`
- `IPConfig.txt`
- `Netstat.txt`
- `Nslookup.txt`
- `Nslookup_localhost.txt`
- `PingMe.txt`
- `RouteDefinition.txt`
- `etc/hosts`
- `etc/network`
- `etc/services`
- `ip_addr.txt`
- `ip_route.txt`
- `ss.txt`
- `ss_deep.txt`
- `ss_time.txt`
